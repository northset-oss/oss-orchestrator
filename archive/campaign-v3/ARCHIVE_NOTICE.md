# Campaign-v3 legacy archive

This directory is the retired pre-factory OSS campaign runtime, moved intact during the Stage D
cutover on 2026-07-19. Its entrypoints, tests, campaign controls, specifications, and supporting files
retain their historical relative layout so the archived test suite can still be run for archaeology
or regression comparison.

Nothing in this directory is an active production entrypoint or policy source. Current operators must
use the root `README.md`, root `OPERATING_CONTRACT.md`, and `factory/cli.mjs`.
